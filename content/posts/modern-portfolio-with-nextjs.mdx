# Building a Modern Portfolio with Next.js 15

In today's competitive tech landscape, having a strong online portfolio is essential for showcasing your skills and landing your dream job. This guide will walk you through building a modern, performant portfolio using Next.js 15 – the latest version of the popular React framework.

## Why Next.js 15?

Next.js 15 brings significant improvements over previous versions:

- **React 19 Support**: Latest React features and optimizations
- **Improved Performance**: Faster builds and better runtime performance
- **Enhanced Developer Experience**: Better error messages and debugging
- **App Router Maturity**: Stable and powerful routing system
- **Server Actions**: Simplified data mutations
- **Built-in Optimizations**: Image optimization, font optimization, and more

## Prerequisites

Before we begin, ensure you have:

- Node.js 20+ installed
- Basic knowledge of React and TypeScript
- Familiarity with modern JavaScript (ES6+)
- A code editor (VS Code recommended)

## Project Setup

Let's start by creating a new Next.js project:

```bash
# Create new Next.js project
npx create-next-app@latest my-portfolio --typescript --tailwind --app

# Navigate into project
cd my-portfolio

# Start development server
npm run dev
```

<Callout type="info">
The `--app` flag enables the App Router, which is the recommended way to build Next.js applications going forward. It provides improved performance, better streaming support, and a more intuitive file-based routing system.
</Callout>

## Implementing Animations with Framer Motion

Add smooth animations to make your portfolio stand out:

```bash
npm install framer-motion
```

```typescript
// app/components/AnimatedSection.tsx
'use client';

import { motion } from 'framer-motion';

interface AnimatedSectionProps {
  children: React.ReactNode;
  delay?: number;
}

export default function AnimatedSection({ children, delay = 0 }: AnimatedSectionProps) {
  return (
    <motion.div
      initial={{ opacity: 0, y: 50 }}
      whileInView={{ opacity: 1, y: 0 }}
      viewport={{ once: true }}
      transition={{ duration: 0.6, delay }}
    >
      {children}
    </motion.div>
  );
}
```

<Callout type="success">
Framer Motion makes it easy to add smooth, performant animations. The `whileInView` trigger ensures animations only play when the user scrolls to that section, improving performance.
</Callout>

## Adding Dark Mode Support

Give users the option to switch between light and dark themes:

```typescript
// app/components/ThemeToggle.tsx
'use client';

import { useEffect, useState } from 'react';

export default function ThemeToggle() {
  const [isDark, setIsDark] = useState(false);

  useEffect(() => {
    const theme = localStorage.getItem('theme');
    if (theme === 'dark' || (!theme && window.matchMedia('(prefers-color-scheme: dark)').matches)) {
      setIsDark(true);
      document.documentElement.classList.add('dark');
    }
  }, []);

  const toggleTheme = () => {
    if (isDark) {
      document.documentElement.classList.remove('dark');
      localStorage.setItem('theme', 'light');
    } else {
      document.documentElement.classList.add('dark');
      localStorage.setItem('theme', 'dark');
    }
    setIsDark(!isDark);
  };

  return (
    <button
      onClick={toggleTheme}
      className="p-2 rounded-lg hover:bg-gray-100 dark:hover:bg-gray-800 transition"
      aria-label="Toggle theme"
    >
      {isDark ? '☀️' : '🌙'}
    </button>
  );
}
```

## Optimizing Images

Next.js 15's Image component provides automatic optimization:

```typescript
import Image from 'next/image';

export default function ProjectImage({ src, alt }: { src: string; alt: string }) {
  return (
    <Image
      src={src}
      alt={alt}
      width={800}
      height={600}
      className="rounded-lg"
      placeholder="blur"
      blurDataURL="data:image/jpeg;base64,/9j/4AAQSkZJRg..."
    />
  );
}
```

<Callout type="warning">
Always provide width and height props to prevent layout shift. Use the placeholder prop for a better user experience while images load.
</Callout>

## Adding Analytics

Track visitor behavior with PostHog:

```bash
npm install posthog-js
```

```typescript
// app/providers.tsx
'use client';

import PostHogProvider from './PostHogProvider';

export default function Providers({ children }: { children: React.ReactNode }) {
  return <PostHogProvider>{children}</PostHogProvider>;
}

// app/PostHogProvider.tsx
'use client';

import { useEffect } from 'react';
import posthog from 'posthog-js';

export default function PostHogProvider({ children }: { children: React.ReactNode }) {
  useEffect(() => {
    if (typeof window !== 'undefined') {
      posthog.init(process.env.NEXT_PUBLIC_POSTHOG_KEY!, {
        api_host: process.env.NEXT_PUBLIC_POSTHOG_HOST,
        capture_pageview: false,
      });
    }
  }, []);

  return <>{children}</>;
}
```

## Performance Tips

1. **Use Server Components**: Default in Next.js 15, reduces JavaScript bundle
2. **Lazy Load Components**: Load heavy components only when needed
3. **Optimize Images**: Use Next.js Image component with proper dimensions
4. **Code Splitting**: Split code into smaller chunks for faster loads
5. **Use App Router**: Better performance than Pages Router
6. **Enable Caching**: Configure proper caching strategies
