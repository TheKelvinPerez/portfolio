# Getting Started with WordPress Development

WordPress powers over 40% of all websites on the internet, making it the most popular content management system in the world. Whether you're looking to build custom themes, develop plugins, or simply enhance your web development skills, WordPress development is a valuable skill to master.

## Why WordPress Development?

WordPress development offers numerous advantages:

- **Huge Market Demand**: Millions of businesses need WordPress developers
- **Flexible Architecture**: Build anything from simple blogs to complex e-commerce sites
- **Strong Community**: Access to thousands of themes, plugins, and resources
- **Open Source**: Free to use, modify, and distribute
- **Career Opportunities**: Freelance, agency, or full-time positions available

## Setting Up Your Development Environment

Before diving into WordPress development, you need a proper local development environment. Here's what you'll need:

### 1. Local Server Environment

You can choose from several options:

- **LocalWP** (Recommended): Easiest to set up with a GUI interface
- **XAMPP/MAMP**: Traditional local server stack
- **Docker**: For containerized development environments
- **WP-CLI**: Command-line interface for WordPress management

### 2. Code Editor

Choose a powerful code editor like:
- VS Code (with PHP Intelephense extension)
- PhpStorm (full-featured PHP IDE)
- Sublime Text (lightweight option)

### 3. Development Tools

Essential tools for WordPress development:

```bash
# Install WP-CLI globally
curl -O https://raw.githubusercontent.com/wp-cli/builds/gh-pages/phar/wp-cli.phar
chmod +x wp-cli.phar
sudo mv wp-cli.phar /usr/local/bin/wp

# Verify installation
wp --info
```

## Understanding WordPress Architecture

WordPress follows a specific architecture that you need to understand:

### Core Structure

- **wp-admin**: Administrative interface and dashboard
- **wp-includes**: Core WordPress functionality and libraries
- **wp-content**: Your themes, plugins, and uploads (this is where you'll work)

### Template Hierarchy

WordPress uses a template hierarchy to determine which PHP file loads for different content types:

1. `front-page.php` - Front page
2. `single.php` - Single post
3. `page.php` - Single page
4. `archive.php` - Archive pages
5. `index.php` - Fallback template

## Building Your First Custom Theme

Let's create a simple custom theme from scratch:

### Step 1: Create Theme Directory

```bash
cd wp-content/themes/
mkdir my-custom-theme
cd my-custom-theme
```

### Step 2: Create Required Files

```bash
# Create style.css with theme information
touch style.css

# Create functions.php for theme functionality
touch functions.php

# Create index.php as the main template
touch index.php
```

### Step 3: Add Theme Information

In `style.css`, add:

```css
/*
Theme Name: My Custom Theme
Theme URI: https://example.com/my-custom-theme
Author: Your Name
Author URI: https://example.com
Description: A simple custom WordPress theme
Version: 1.0.0
License: GNU General Public License v2 or later
License URI: http://www.gnu.org/licenses/gpl-2.0.html
Text Domain: my-custom-theme
*/

/* Add your custom styles below */
```

### Step 4: Create Basic Template

In `index.php`:

```php
<?php get_header(); ?>

<main class="site-main">
  <?php
  if (have_posts()) :
    while (have_posts()) : the_post();
      ?>
      <article <?php post_class(); ?>>
        <h2><a href="<?php the_permalink(); ?>"><?php the_title(); ?></a></h2>
        <div class="entry-content">
          <?php the_excerpt(); ?>
        </div>
      </article>
      <?php
    endwhile;

    the_posts_navigation();
  else :
    echo '<p>No posts found.</p>';
  endif;
  ?>
</main>

<?php get_footer(); ?>
```

<Callout type="info">
WordPress uses a template tag system. Functions like `get_header()`, `the_title()`, and `the_content()` are built-in functions that output specific content.
</Callout>

## Essential WordPress Functions

Here are the most important WordPress functions you'll use:

### Content Functions

```php
// Get post title
the_title(); // Echo title
get_the_title(); // Return title

// Get post content
the_content(); // Echo content with formatting
get_the_content(); // Return raw content

// Get post excerpt
the_excerpt(); // Echo excerpt
get_the_excerpt(); // Return excerpt

// Get post permalink
the_permalink(); // Echo URL
get_permalink(); // Return URL
```

### Conditional Functions

```php
// Check if single post
is_single()

// Check if page
is_page()

// Check if front page
is_front_page()

// Check if user is logged in
is_user_logged_in()

// Combined condition
if (is_single() && 'post' === get_post_type()) {
  // Do something
}
```

## Plugin Development Basics

Plugins allow you to extend WordPress functionality without modifying theme files.

### Basic Plugin Structure

Create `wp-content/plugins/my-first-plugin/my-first-plugin.php`:

```php
<?php
/*
Plugin Name: My First Plugin
Plugin URI: https://example.com/my-first-plugin
Description: A simple WordPress plugin
Version: 1.0.0
Author: Your Name
Author URI: https://example.com
License: GPL v2 or later
*/

// Prevent direct access
defined('ABSPATH') || exit;

// Add shortcode
add_shortcode('greeting', function($atts) {
  $atts = shortcode_atts([
    'name' => 'World'
  ], $atts);

  return "Hello, {$atts['name']}!";
});
```

Now you can use `[greeting name="John"]` in any post or page.

## Best Practices for WordPress Development

### 1. Security

<Callout type="warning">
Always sanitize and validate user input. Never trust data from $_GET, $_POST, or database queries.
</Callout>

```php
// Sanitize input
$name = sanitize_text_field($_POST['name']);

// Escape output
echo esc_html($name);

// Prepare database queries
global $wpdb;
$result = $wpdb->prepare(
  "SELECT * FROM {$wpdb->prefix}users WHERE ID = %d",
  $user_id
);
```

### 2. Performance

- Use `wp_enqueue_script()` and `wp_enqueue_style()` for assets
- Optimize images before uploading
- Use caching plugins (WP Rocket, W3 Total Cache)
- Minimize HTTP requests
- Use a CDN for static assets

### 3. Child Themes

<Callout type="success">
Always use child themes when modifying existing themes. This ensures your changes aren't lost when the parent theme updates.
</Callout>

```bash
# Create child theme directory
mkdir wp-content/themes/twentytwentyfour-child

# Create style.css
/*
Theme Name: Twenty Twenty-Four Child
Template: twentytwentyfour
*/

# Create functions.php
add_action('wp_enqueue_scripts', function() {
  wp_enqueue_style(
    'parent-style',
    get_template_directory_uri() . '/style.css'
  );
});
```
