# Mastering GSAP Animations in Web Development

Animations bring websites to life, creating engaging user experiences that capture attention and guide users through content. Among the many animation libraries available, GSAP (GreenSock Animation Platform) stands out as the industry standard for creating high-performance, professional animations.

## Why GSAP?

GSAP offers numerous advantages:

- **Performance**: Up to 20x faster than jQuery
- **Flexibility**: Animate any property (CSS, SVG, Canvas, etc.)
- **Robustness**: Handles complex sequencing with ease
- **Compatibility**: Works across all modern browsers
- **Documentation**: Extensive docs and active community
- **Free for Most Uses**: Only paid for commercial games/resale

## Core Concepts

### Tween Types

GSAP provides three main types of tweens:

```javascript
// 1. to() - Animate to specific values
gsap.to('.element', {
  x: 100,
  duration: 1
});

// 2. from() - Animate from specific values
gsap.from('.element', {
  opacity: 0,
  y: 50,
  duration: 1
});

// 3. fromTo() - Define both start and end
gsap.fromTo('.element',
  { opacity: 0, scale: 0 },
  { opacity: 1, scale: 1, duration: 1 }
);
```

### Easing Functions

Easing defines how animations progress:

```javascript
gsap.to('.element', {
  x: 100,
  duration: 1,
  ease: 'power2.out'  // Common easing
});

// Available easings:
// - power0, power1, power2, power3, power4
// - back, bounce, elastic, steps
// - none, linear
```

<Callout type="info">
The `.out` suffix makes animations feel more natural by easing out at the end. Use `.in` for easing in, or `.inOut` for both.
</Callout>

## Timelines: Sequencing Animations

Timelines are GSAP's superpower – they let you sequence multiple animations:

```javascript
const tl = gsap.timeline();

tl.from('.header', { y: -100, opacity: 0, duration: 0.5 })
  .from('.hero-text', { x: -50, opacity: 0, duration: 0.5 }, '-=0.25')
  .from('.hero-button', { scale: 0, duration: 0.3 }, '-=0.1');
```

The `-=0.25` creates overlap, making animations more dynamic.

### Timeline Control

```javascript
const tl = gsap.timeline();

// Playback controls
tl.pause();
tl.play();
tl.reverse();
tl.restart();

// Jump to specific point
tl.seek(1); // Jump to 1 second
tl.progress(0.5); // Jump to 50% complete

// Speed control
tl.timeScale(2); // 2x speed
tl.timeScale(0.5); // 0.5x speed (slow motion)
```

## ScrollTrigger: Scroll-Based Animations

ScrollTrigger is GSAP's most popular plugin:

```bash
npm install @gsap/react
```

```javascript
import { ScrollTrigger } from 'gsap/ScrollTrigger';
import gsap from 'gsap';

gsap.registerPlugin(ScrollTrigger);

// Animate when element enters viewport
gsap.to('.box', {
  scrollTrigger: '.box',
  x: 500,
  duration: 2
});

// Pin element during scroll
gsap.to('.panel', {
  scrollTrigger: {
    trigger: '.panel',
    pin: true,
    start: 'top top',
    end: '+=500'
  }
});
```

<Callout type="success">
ScrollTrigger transforms how users experience your content. Use it for parallax effects, reveal animations, and scroll-based storytelling.
</Callout>

### Scroll Reveal Animation

```javascript
// Reveal sections as you scroll
gsap.utils.toArray('.reveal').forEach(section => {
  gsap.from(section, {
    scrollTrigger: {
      trigger: section,
      start: 'top 80%',
      end: 'bottom 20%',
      toggleActions: 'play none none reverse'
    },
    y: 100,
    opacity: 0,
    duration: 0.8,
    ease: 'power2.out'
  });

```

### Stagger Animation

```javascript

gsap.from('.card', {
  y: 100,
  opacity: 0,
  duration: 0.6,
  stagger: 0.1, // Delay each by 0.1s
  ease: 'power2.out'

```

## Advanced Techniques

### MorphSVG: Shape Morphing

```bash

```

```javascript
import { MorphSVGPlugin } from 'gsap/MorphSVGPlugin';
gsap.registerPlugin(MorphSVGPlugin);

gsap.to('#shape1', {
  morphSVG: '#shape2',
  duration: 2,
  ease: 'elastic.out(1, 0.3)'

```

### DrawSVG: Line Animation

```javascript

gsap.registerPlugin(DrawSVGPlugin);

gsap.from('#path', {
  drawSVG: '0%',
  duration: 2,
  ease: 'power2.inOut'
});
```

### Motion Path: Animate Along Path

```javascript

gsap.to('.box', {
  motionPath: {
    path: '#path',
    align: '#path',
    autoRotate: true
  },
  duration: 3,
  ease: 'power1.inOut'
});
```

## Performance Best Practices

### 1. Use Will-Change

```css
.animate {
  will-change: transform, opacity;
}
```

### 2. Prefer Transform Properties

```javascript
// ✅ Good - uses GPU
gsap.to('.box', { x: 100, scale: 1.5 });

// ❌ Avoid - triggers layout
gsap.to('.box', { width: '100%', height: '200px' });
```

### 3. Batch DOM Reads/Writes

```javascript
// ✅ Efficient
const elements = gsap.utils.toArray('.box');
gsap.to(elements, { x: 100 });

// ❌ Less efficient
document.querySelectorAll('.box').forEach(el => {
  gsap.to(el, { x: 100 });
});
```

<Callout type="warning">
Avoid animating layout properties like width, height, padding, or margin. These trigger expensive layout recalculations. Use transform instead.
</Callout>

### 4. Use GSAP's Built-in Optimization

```javascript
gsap.to('.box', {
  x: 100,
  force3D: true,    // Force GPU acceleration
  autoRound: false, // Prevent unnecessary rounding
  duration: 1
});
```

## React Integration

GSAP works seamlessly with React using `@gsap/react`:

```typescript
'use client';

import { useEffect, useRef } from 'react';
import gsap from 'gsap';

export default function AnimatedBox() {
  const boxRef = useRef<HTMLDivElement>(null);

  useEffect(() => {
    if (!boxRef.current) return;

    gsap.fromTo(
      boxRef.current,
      { scale: 0, rotation: -180 },
      { scale: 1, rotation: 0, duration: 1, ease: 'elastic.out(1, 0.5)' }
    );
  }, []);

  return <div ref={boxRef} className="w-20 h-20 bg-blue-500 rounded" />;
}
```

### ScrollTrigger in Next.js

```typescript
'use client';

import { useEffect, useRef } from 'react';
import { ScrollTrigger } from 'gsap/ScrollTrigger';
import gsap from 'gsap';

gsap.registerPlugin(ScrollTrigger);

export default function ScrollReveal({ children }: { children: React.ReactNode }) {
  const containerRef = useRef<HTMLDivElement>(null);

  useEffect(() => {
    if (!containerRef.current) return;

    gsap.from(containerRef.current, {
      scrollTrigger: {
        trigger: containerRef.current,
        start: 'top 80%',
        toggleActions: 'play none none reverse'
      },
      y: 100,
      opacity: 0,
      duration: 0.8
    });

    return () => {
      ScrollTrigger.getAll().forEach(trigger => trigger.kill());
    };
  }, []);

  return <div ref={containerRef}>{children}</div>;
}
```

## Common Animation Patterns

### Magnetic Button Effect

```javascript
const button = document.querySelector('.magnetic-btn');

button.addEventListener('mousemove', (e) => {
  const rect = button.getBoundingClientRect();
  const x = e.clientX - rect.left - rect.width / 2;
  const y = e.clientY - rect.top - rect.height / 2;

  gsap.to(button, {
    x: x * 0.3,
    y: y * 0.3,
    duration: 0.3,
    ease: 'power2.out'
  });
});

button.addEventListener('mouseleave', () => {
  gsap.to(button, { x: 0, y: 0, duration: 0.5, ease: 'elastic.out(1, 0.3)' });
});
```

### Text Split Animation

```javascript
const text = document.querySelector('.animate-text');
const letters = text.textContent.split('');
text.innerHTML = letters
  .map(letter => `<span class="letter">${letter}</span>`)
  .join('');

gsap.from('.letter', {
  y: 100,
  opacity: 0,
  stagger: 0.05,
  duration: 0.5,
  ease: 'back.out(1.7)'
});
```

### Counter Animation

```javascript
const counter = { value: 0 };
const targetValue = 1000;

gsap.to(counter, {
  value: targetValue,
  duration: 2,
  ease: 'power2.out',
  onUpdate: () => {
    document.querySelector('.counter').textContent =
      Math.round(counter.value);
  }
});
```
